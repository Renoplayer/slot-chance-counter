# チャンス目カウンター

画像のチャンス目種類・pt表に合わせて作り直したFlask製カウンターです。

## チャンス目のpt
- 【通常】チャンス目（発光なし）: 1pt
- 【通常】チャンス目（発光あり）: 15pt
- 【高確】チャンス目（帯付き）: 15pt
- 【通常】複合チャンス目: 15pt
- 【高確】複合チャンス目: 30pt
- 【通常】オールスター目: 30pt
- 【高確】オールスター目: 60pt

## 起動
```bash
pip install flask
python app.py
```
ブラウザで http://127.0.0.1:5000 を開いてください。

データはブラウザのlocalStorageに保存します。SQLite等は不要です。
